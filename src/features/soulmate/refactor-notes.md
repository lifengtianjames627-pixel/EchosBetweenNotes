# 招募与附近发现：2026-10-04

## 本轮范围
- 附近发现仅接受 User 上的 minor/adult 自报年龄组；双方年龄未知或不同则不推荐，不从历史帖子反推年龄。未声明者可从首页/消息页进入现有年龄声明页，历史私信保持不变。
- 招募读取规则在存储层执行同年龄、活跃、审核通过（兼容历史空状态）限制，作者保留自己的内容读取/删除，管理员保留审核访问。
- 创建必须是本人邮箱、本人有效年龄组、pending_review；普通作者不能直接更新审核结果。发布改为 publishRecruitPost：校验正文/标签/角色中的联系方式、声明与字段，服务端设置作者身份，复用现有文字审核，异常转人工待审，不直接放行。
- 图片帖子进入人工审核；ModerationQueue 增加招募审核卡片与通过/拒绝操作。通过后列表刷新，拒绝时先移除旧的公开卡片和对应附近推荐缓存，再重新读取，避免显示已拒绝的旧缓存。
- 新增界面提示提供六语言；年龄提示强调自报不等于真实年龄核验。提高年龄提示与手机招募介绍的文字对比度。

## 已验证
- 构建通过，两个后端入口测试可调用；不接受协议返回 INVALID_DRAFT，站外联系方式返回 CONTACT。
- 预览中的当前管理员临时取消自己的年龄后：附近目录返回空且提示需要年龄；首页、消息页显示入口；真实点击进入年龄选择、继续保存，持久值匹配；缺少年龄的发布请求返回 AGE_REQUIRED。
- 发帖表单真实输入与提交：长数字测试标题触发联系方式提示；另一条文字测试触发现有内容审核 MODERATION，草稿保留并显示可理解的拒绝说明。
- 从实际发布函数创建的临时图片招募保存为待审，作者身份和年龄由服务端填充；公开看板不显示待审。
- 真实点击管理员通过后，存储为 approved 且看板可见；真实点击拒绝后，存储为 blocked，修复缓存后返回看板立即隐藏。
- 审核卡片实际图片加载并显示；手机年龄选择与招募页渲染，无文档横向溢出。首页、消息页、招募页、审核页的当前管理员路径可达。
- 所有临时记录按本轮创建返回的 ID 删除；原有年龄及测试修改的偏好恢复，无其他用户记录更改。

## 未验证与遗留边界
- 普通用户、不同年龄账户、游客的真实跨身份 RLS 拒绝尚未自动验证；当前只有管理员身份，不能把管理员结果当成普通用户隔离通过。
- 文字表单成功发布路径未通过本次验证，测试文案被现有 moderateContent 判为 block；未改其分类策略，后续需单独评估招募文字误判。
- 未模拟审核服务停机；失败转待审路径来自代码检查，不声称故障注入通过。
- 自报年龄可通过用户资料接口修改；不是身份核验，也不是全站私信/搜索/资料的年龄隔离。历史帖子年龄与后来修改的年龄之间仍需独立策略。
