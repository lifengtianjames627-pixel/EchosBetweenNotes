# 播客频道、管理员发布与私有音频

日期：2026-10-09

## 范围与实现
- 六个原有频道及原有地址保留，首页改为统一浅奶油纸底、书信水彩封面和网格；频道详情、节目卡片、编辑说明及上传窗口沿用同一套语义颜色。六张插画为公开静态频道资产，音频不因封面公开而变为公开文件。
- 展示、领域查询、表单、本地试听、播放器和六语言文案分别放在 podcasts 领域内；原有主持人站内联系保留，名字使用 publicName，用户节目正文保持原文。
- 管理员发布：客户端仅管理员显示上传窗口，publishPodcast 在服务端认证并校验管理员；Podcast 与 PodcastAudioAsset 的创建、更新、删除限管理员，音频资产直接读取也限管理员。Podcast 公开读取仅提供节目元数据和不含存储URI的资产引用。
- 上传支持 WAV、MP3、M4A、AAC、OGG、OPUS、FLAC、WEBM 扩展名，最大50 MB。服务端检查文件头与扩展名，规范音频MIME后走 UploadPrivateFile；浏览器本地试听和读取时长成功后才允许发布。保留原格式，不提供服务端转码，不保证所有设备支持每种编码。
- 没有预上传步骤：取消草稿不会上传。发布失败提供保留草稿的错误信息；节目创建失败时清理已经创建的资产记录，但底层已上传文件没有已文档化的删除接口。
- getPodcastAudio 要求登录，先查可读节目，再以其资产ID查询受限资产并签发3600秒临时链接；不接受调用者提供的存储URI。链接是有效期内的持有人凭据，不保证已下载副本可撤销；错误时可重新请求链接。游客可浏览频道/节目元数据，但须登录后获取新音频播放地址。
- 改动前Podcast记录数为0，没有迁移或修改真实节目。历史audio_url字段保留兼容，不能据此承诺外部历史公开文件已被私有化。
- 节目按频道服务端过滤，每页20集，可加载下一页；频道计数和时长使用服务端aggregate，发布后刷新节目、汇总及既有homeFeed缓存。

## 当前检查
- 规范检查、完整类型检查与生产构建通过。没有关闭检查或新增依赖。
- publishPodcast 无音频JSON请求返回400；getPodcastAudio 非法节目ID返回400。
- 当前管理员路径通过：六个实际频道链接及对应标题、六张封面加载、桌面/手机布局、空草稿禁用、错误文件拒绝、WAV原生文件输入change路径、本地1秒试听元数据、真实表单发布、节目与私有资产持久化、时长保存、实际收听入口获取临时链接、音频元素成功加载且无解码错误、取消/关闭及焦点恢复；没有新增控制台错误。
- 计数第一次在异步汇总完成前采样未通过，后续记录的实际aggregate响应确认该频道count为1；没有把第一次即时界面断言写成通过，也没有为测试修改计数逻辑。
- 浏览器原生播放/暂停手势未自动验证，自动播放未启动；只将加载与解码检查写成通过，不声称已经自动验证播放按钮。浏览器原生controls仍可用于手动播放。
- 第一次导航工具在参数地址已经渲染时报告无法确认渲染；不更改产品路由，随后使用实际链接与明确标题断言确认全部六个频道通过。
